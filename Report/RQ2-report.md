# RQ-2 实验报告

## 一、任务描述

本实验目的是测试LLM在根据问题检索相关论文和生成对应solution的能力。

实验分为三个部分：

RQ2-1 ：Testing whether the LLM has the ability to generate corresponding related work.

Input： Observation

Output： Related works and core claim.

GroundTruth :  human generated Related works and core claim.

RQ2-2: Testing the ability of the LLM to generate solutions

Input : Observation and related works (From human)

Output : Solution

GroundTruth :  human generated solution.

RQ2-3: Test the influence of the LLM-generated "related work" and "human-related work" on generating the final solution.

Input : Observation and related works(generated by LLM)  /  Observation and related works(generated by human) 

Output : Solutions

Target: Compare the impact of the two input pairs on the solution.

## 二、实验流程

1. 论文信息抽取：以论文[Let the Barbarians In: How AI Can Accelerate Systems Performance Research](https://arxiv.org/pdf/2512.14806#page=19&zoom=100,430,470)中的ADRS任务的论文作为数据来源。（一共10个任务，两个任务来源于同一篇论文，一个任务没有文本论文，因此共8篇）
   使用Deepseek-v4-flash进行论文信息抽取。主要包含三个部分：
   - Observation：论文作者观察到的领域问题。
   - Related works：根据Observation调研的相关工作，以claims和支撑works形式出现。即一条claims后续跟着几个支撑其观点的论文工作。
   - Solution：论文作者提出的解决方案。分为idea和implement两个部分，分别代表思路和具体实现。

2. LLM生成相关内容：
   2.1 给LLM提供人类Observation，使其给出相关领域的论文，作为Related works的支撑工作，并且给出claims。为了保证风格，长短一致，在提示词中加入其他论文的人类相关工作结果，便于参考。实验两次，分别在提示词中禁止模型检索，和要求模型进行检索，得到两个结果。
   2.2 给LLM提供人类Observation，Related works（人类，LLM禁止检索，LLM允许检索）。分三次得到solution。为了确保风格长短，形式一致，在提示词中加入其他论文的人类Solution，便于参考。
   2.3 整合生成结果，共有四个结果文件，内容如下表所示：

   | Source | Observation | Related works      | Solution |
   | ------ | ----------- | ------------------ | -------- |
   | Human  | Human       | Human              | Human    |
   | LLM-1  | Human       | Human              | LLM      |
   | LLM-2  | Human       | LLM-with-search    | LLM      |
   | LLM-3  | Human       | LLM-without-search | LLM      |

### 3.1 RQ2-1：LLM 生成 Related Works 与 Core Claim 的能力

**对比对象**：Human & LLM-2（with-search 变体）、Human & LLM-3（without-search 变体）。即分别用人类相关工作集合 $S_H$ 对比两个 LLM 变体生成的 $S_L$。

**评测流程（依据 evaluation-guide.md §1）**：先将 $S_H$、$S_L$ 中的非结构化引用解析为 (Title, Authors, Year) 元数据三元组，再调用 Semantic Scholar (S2) API 获取 `s2_id`、`doi`、`citationCount`、`venue` 及 SPECTER2 向量，最后经三级匹配判定算法（L1：DOI/S2ID 精确匹配；L2：JaroWinkler(标题) ≥ 0.90 且年份差 ≤ 1；L3：SPECTER2 余弦相似度 ≥ 0.92）生成判定矩阵 $M_{i,j} \in \{0,1\}$，得到匹配交集 $S_M = S_H \cap S_L$。**S2 无法检索到的论文视为编造或失败记录**，仅用于参考其质量，不参与匹配。

**RQ2-1 关键指标口径说明（表 3-3 / 3-7 中的 RR、W1、Rel，实现口径于 2026-09 逐项核对评测代码）**：

- **RR（Recency Ratio，近 3 年论文占比）**：基准年份**不是各观测论文自身的发表年份，而是固定的评测当年 2026**（`config.CURRENT_YEAR` 取程序运行年份，窗口 `RECENT_YEARS = 3` 年）。一篇被引论文记为"近期"当且仅当 `2026 − Year_p ≤ 3`（即发表在 2023–2026 年区间）；RR(S) = 近期论文数 / |S|。年份缺失的论文无法判定，留在分母中按"非近期"计（每侧实际有年份的论文数见评估输出）。注意：8 篇观测论文本身发表于不同年份，若改用"观测论文发表后 3 年内"的滑动基准，RR 会得到不同取值——本实验统一固定 2026 基准，便于 8 个样本之间横向比较。
- **W1（发表年份分布差异，单位：年）**：在**同一观测论文内部**，把人类文献集与 LLM 文献集各自的论文发表年份看成两个经验分布，计算两者累积分布函数之差的绝对积分 W1 = ∫|F_H(x) − F_L(x)|dx。它是**对称且非负的"距离"量，没有"谁相对谁更新/更旧"的正负方向**：W1 = 0 表示两侧年份分布完全相同（该论文的人类与 LLM 引用文献新旧结构一致），W1 越大表示两侧分布差异越大（例如一侧集中于近几年、另一侧年份跨度更大或更偏旧）。实现按离散年份分段精确积分，两侧缺失年份的论文从分布中剔除（评估输出中各有有效样本数）。
- **Rel（Observation 贴合度）**：对文献集 S 中的每篇论文 p，取其 **S2 规范化标题 + 摘要拼接文本**（SPECTER2 预训练输入格式 `"title: …\n abstract: …"`；S2 无摘要的论文仅用标题）经 SPECTER2 编码为论文向量 $v_p$；同时用同一编码器把该论文的 **Observation 文本**（人类撰写的观察描述，即本报告"输入"中的 Observation）编码为 $v_{\text{obs}}$。贴合度 $\text{Rel}(S, \text{Obs}) = \frac{1}{|S|}\sum_p \cos(v_p, v_{\text{obs}})$。因此表 3-3/3-7 中的 Rel(H)/Rel(L) 分别衡量人类/LLM 所选文献集合与 Observation 的整体语义贴合程度（其余语义指标"类内/类间"同样基于上述标题+摘要向量计算）。正文默认使用编码器 `allenai/specter2_base`；针对"相似度普遍偏高、区分性弱"的疑问，另以官方推荐的 `allenai/specter2`（base+proximity 适配器）与 `scibert_scivocab_uncased` 做了三编码器敏感性对照（独立输出、不覆盖主结果），见文末**附录：语义编码器敏感性对照**。

### 3.2 RQ2-2：基于人类 Related Work 的 Solution 生成能力

**对比对象**：Human & LLM-1。即输入 Observation + 人类 Related Works（$S_H$），由 LLM 生成 Solution（$\text{Sol}_L$），与人类 Solution（$\text{Sol}_H$）对比。

**评测流程（依据 evaluation-guide.md §2）**：
- **四维 Rubric 打分（§2.1）**：由 LLM 裁判按 1–5 分对方案的四个维度打分——针对性（$s_{\text{tgt}}$，是否精准应对 Observation 的核心矛盾）、技术可行性（$s_{\text{feas}}$，数学/逻辑/工程原理是否存在漏洞）、创新性（$s_{\text{nov}}$，是否突破简单堆叠 Baseline 的平庸解）、继承性（$s_{\text{grd}}$，是否显式且合理地利用了输入 $S_H$ 中的技术路线）；综合质量得分为加权总分，**权重采用均权 w = 0.25**（即四维平均，实际运行配置见评估代码 config.SOL_WEIGHTS）。
- **语义嵌入相似度（§2.2.1）**：使用学术领域文本模型（如 SciNBERT）提取方案文本向量并计算余弦相似度 $\cos(v_{\text{Sol}_L}, v_{\text{Sol}_H})$。
- **关键技术要素覆盖率 AspectRecall（§2.2.2）**：将 $\text{Sol}_H$ 抽取为 $K$ 个关键技术要素（损失函数改进、新网络模块、启发式算法等），统计 $\text{Sol}_L$ 覆盖的比例。
- 另外将人类 Solution 放入同一上下文 rubric 中打分作为**人类基线对照**（§2.1b），使 LLM 分值与人类真实水平在同一裁判口径下可比。

### 3.3 RQ2-3：LLM-RW 与 Human-RW 对 Solution 产出的影响对比与归因

**对比对象**：LLM-1 & LLM-2（with-search 变体）、LLM-1 & LLM-3（without-search 变体）。即输入 A = Observation + LLM 生成的 Related Works（$S_L$）生成的 Solution，输入 B = Observation + 人类 Related Works（$S_H$）生成的 Solution（即 RQ2-2 产出），比较两种相关工作的输入对最终方案质量的影响。

**评测流程（依据 evaluation-guide.md §3）**：
- **位置对调双盲成对评估（§3.1）**：为消除 LLM 裁判的位置偏置，每个样本评估两轮（第一轮 A/B 位置正常，第二轮位置对调），两次判定无冲突才有效，冲突标记为 `Tie`。胜率 WinRate 为「输入 LLM-RW 的方案在两轮判定中胜出」的样本占比；方案得分差值为四维度逐维差值 $\Delta_i^{(k)} = \text{Score}^{(k)}(\text{Sol}_{\text{LLM\_RW}}) - \text{Score}^{(k)}(\text{Sol}_{\text{Human\_RW}})$ 的成对两轮均值。
- **交叉裁判稳定性（实际运行）**：主裁判后端 qwen，交叉裁判后端 deepseek 对同一批双盲任务复核；另开启 **identical-pair 控制实验**（A 与 B 为同一方案，理想输出应全部为 Tie），用于检验裁判是否存在位置偏置/凭空制造差异的倾向。
- **归因分析（§3.2）**：将 RQ2-1 中 LLM 相关工作各质量指标（Recall、Rel、幻觉率 = 1/Precision）与 RQ2-3 中对应方案得分差值做 Spearman 等级相关，检验三项假设——检索召回假说（recall → 继承性差值，预期正相关）、贴合度传导假说（Rel → 针对性差值，预期正相关）、幻觉/噪音干扰假说（幻觉率 → 可行性差值，预期负相关）。
- *说明：两变体文件中 "Sol_HumanRW" 为同一批 LLM-1 方案（人类 RW 输入）在两次独立成对评估中重新打分的结果，同一样本两文件得分存在小幅波动（如 52875bf8ef4b3f8c：3.8750 vs 3.6250），按各自评估输出原样保留。*

#### 3.3.3 RQ2-3 小结

1. **偏好层面（有效判定）不存在系统性胜者**：修正标签映射解析后，主裁判 qwen 在两个变体的 16 个样本上无一形成两轮一致的有效判定（除 2 个含 Tie 的样本外全部为"两轮偏好相反"的冲突）——其二元偏好每轮都指向"先展示"的方案，对展示顺序敏感，无法支撑胜率结论。原初版报告中的"qwen WinRate 75.0%、人类 RW 0 胜"是该顺序敏感性被标签解析 bug 误读为"一致胜出"的假象（见本节勘误说明）。
2. **deepseek 交叉裁判给出少量、自洽的有效判定**：修正后 deepseek 在 with-search 变体上 5dd2d839c66d339a 两轮一致选 LLM-RW 输入方案（Win_LLM）、e3d82bafe7cb11e7 两轮一致选人类 RW 输入方案（Win_Human）；在 without-search 变体上 5dd2d839c66d339a 同样两轮一致 Win_LLM，其余样本两轮均 Tie。其判定与其每轮四维打分方向自洽，且 identical-pair 控制组全部通过，故这些有效判定可信——但样本太少，仅能说明"个别样本上存在方向明确且可复现的偏好"，且两个方向各有一例，不构成系统性优势证据。
3. **分数层面（Δ 与 3.1c 独立 Rubric）仍有小幅且一致的差异**：Δ total 在 16 个样本上全部为正（0.25–1.125），与 qwen 非盲独立 Rubric 的方向一致，增益集中在可行性与继承性维度——若以连续打分而非二元偏好衡量，LLM-RW 输入方案略占优；但 qwen 在同一轮的偏好输出与其自身打分相矛盾（O2 轮偏好人类 RW 输入方案却给 LLM-RW 输入方案更高分），提示两通道不应混用。
4. **归因**：两次变体共 6 个 Spearman 相关全部不显著，且无一个假说在两个变体上方向一致地成立——相关工作质量指标（recall/Rel/幻觉率）与方案得分差值之间不存在可测的传导关系，RQ2-1 中 LLM 相关工作的低召回、幻觉等缺陷**并未**在 RQ2-3 中体现为方案质量损失。
5. **机制推测（谨慎表述）**：结合 RQ2-1（LLM-RW 与人类 RW 语义高度同向、质量与主题贴合度不低）与 RQ2-2（无论哪种 RW 输入，LLM 方案本身质量稳定在较高水平），一种自洽的解释是——方案质量主要由 LLM 自身的生成能力决定，相关工作的输入差异在其影响方案质量之前已被"吸收"；幻觉文献与低召回对方案造成的负面影响在本批样本上未显现（deepseek 在 e3d82bafe7cb11e7 上甚至两轮偏好人类 RW 输入方案，方向相反的反例同样说明输入差异的效果不具一致性）。该推测仅为解释性观察，受限于样本量，未做统计检验。

### 3.4 综合结论与讨论

#### 3.4.1 对三个子任务问题的回答

**RQ2-1（LLM 能否生成相应的 Related Works 与 Core Claim）**：能，且忠实度高、主题方向准确，但与人类选文的硬重合有限、篇幅短、信息完备性不足——两个变体的召回率均值仅 14.8%–15.7%（人类集合远大于 LLM 输出，LLM 平均每样本 7.5–8.1 篇 vs 人类 36 篇），精确率 60.8%–66.4%，Jaccard 约 0.14；语义层面与人类文献集的质心余弦 ≥ 0.96、贴合 Observation 的程度（Rel）与人类相当；平均对数引用量在全部 8 样本、两个变体上均高于人类，说明 LLM 偏爱引用高影响文献。Core Claim 的 NLI 事实忠实度 ≥ 0.99（with-search 有 1 个样本无有效判定），逻辑分 3–5，但仅覆盖人类原子断言 8.6%–36.1%。**开启检索（with-search）并未带来硬检索指标的提升**（召回 15.7% vs 14.8% 基本持平；精确率 60.8% vs 66.4% 反而更低），且 S2 检索失败率更高（18.5% vs 13.3%，人类侧为 8.0%），检索变体的幻觉参考率不降反升。

**RQ2-2（LLM 能否基于人类相关工作生成 Solution）**：能，且在文本层面高度贴近人类——与人类方案的语义余弦均值 0.947（0.938–0.959）；四维 Rubric 加权总分均值 4.41，高于同裁判口径下的人类基线 4.19（+0.22），其中继承性（4.375 vs 3.875）与创新性（4.25 vs 4.00）维度优势最明显，可行性略高（4.00 vs 3.875），针对性持平（5.00 vs 5.00）；逐样本 Δ total 0.00–+0.50，5 个样本超过人类基线、3 个打平（5dd2d839c66d339a、c252b8a901feea74、d18c13d036b3708f）、无样本低于基线。**主要短板在关键技术要素覆盖率**：AspectRecall 均值仅 50.6%（0.0%–81.8%），f948850caef3d25f 出现"Rubric 高分（4.50）+ 要素覆盖 0/10"的背离。

**RQ2-3（LLM-RW 与 Human-RW 对 Solution 产出的影响）**：修正标签映射解析后（见 3.3 勘误说明），**盲评偏好层面未测得系统性差异**——主裁判 qwen 的二元偏好随展示顺序翻转，两个变体 16 个样本全部按冲突规则判 Tie；交叉裁判 deepseek 仅给出少量两轮一致的有效判定（5dd2d839c66d339a 在两个变体上均选 LLM-RW 输入方案，e3d82bafe7cb11e7 在 with-search 变体上选人类 RW 输入方案），同样不构成系统性优势证据，其中 e3d82bafe7cb11e7 还是方向相反的一例。**分数层面**（qwen 连续打分，独立于偏好）差异反而一致且全部为正：Δ total 在 16 个样本上均为正（0.25–1.125），增益集中在可行性（差值普遍 ≥ 0.5，最大 +2.0）与继承性维度，与非盲独立 Rubric（3.1c）方向一致——即"LLM-RW 输入方案略优"的证据来自打分而非成对偏好。裁判间逐样本一致率修正后为 75.0%（with-search）与 87.5%（without-search）。**归因层面**：六项 Spearman 相关全部不显著且方向在两个变体间不稳定，RQ2-1 中 LLM 相关工作的召回低、幻觉等问题未检测到向最终方案质量的负面传导。

#### 3.4.2 总体发现

1. **"相关工作质量 → 方案质量"的直观传导并未被数据支持**：RQ2-1 中质量最差的样本（如 b93fea400aedf898：Recall 4.0%、Jaccard 0.04）在 RQ2-3 中方案表现并不差，说明 LLM 生成方案的质量更多由其自身能力决定，相关工作的输入差异在影响产出前即被吸收。
2. **LLM 输出的相关工作整体"小而精"**：数量少（约为人类 1/5）、硬重合低，但精确率高、语义同向、引用质量高、幻觉参考率处于可控低位（13.3%–18.5%），作为"供给 LLM 的方案生成上下文"是合格的——这与 RQ2-3 的结果相容：在方案打分层面，以 LLM-RW 为输入不劣于甚至略优于以人类 RW 为输入；在盲评偏好层面则无系统差异。
3. **评估方法层面**：位置对调双盲 + identical-pair 控制 + 独立 Rubric 交叉验证构成了有效的裁判审计体系——它成功暴露了 qwen"二元偏好随展示顺序翻转"的特性（修正解析后其偏好层面无一有效胜者），而 deepseek 的有效判定与其打分自洽；连续打分通道与偏好通道应分开解读。裁判间逐样本一致率修正后为 75.0%–87.5%（初版报告的 25% 系聚合解析 bug 所致），但"胜者"证据仍薄，结论需谨慎外推。

#### 3.4.3 局限性

1. **样本量小（N = 8，单一数据源）**：全部统计相关仅作趋势参考，不具备推断意义；两篇论文（如 b93fea400aedf898、c252b8a901feea74）的表现可能主导部分聚合结论。
2. **裁判行为与结论的裁判依赖**：修正解析后裁判间逐样本一致率（75.0%–87.5%）较高，但两位裁判的"判别方式"不同——qwen 的二元偏好随展示顺序翻转（偏好通道不可用），其结论主要落在连续打分通道（Δ 全为正）；deepseek 判定保守（87.5%–100% Tie）且给出了方向相反的一例（e3d82bafe7cb11e7 偏好人类 RW 输入方案）。有效胜例太少，RQ2-3 的"分数层面略优"结论尚未获得偏好层面的独立复现。
3. **聚合解析的历史缺陷（已修正，留档）**：初版评估输出的胜率/一致率受 o2 标签映射反转 bug 影响（2026-09-07 已修正聚合逻辑并基于原始每轮判定离线重生成，见 3.3 勘误说明）；本报告及评估输出中的判定类数字均为修正后版本，如需追溯可对比 outputs/reports/_backup_20260907/。
4. **同源评分偏差**：人类基线的 Rubric 分亦由 LLM 裁判给出（同上下文口径），绝对分数含裁判偏好成分；LLM 方案得分"高于"人类基线（4.41 vs 4.19）的解读应保持克制。
5. **指标口径边界**：S2 检索失败仅作为"编造/失败"的参考口径（可能与元数据差异、标题年份变体有关），不等于幻觉的严格判定；关键技术要素覆盖率依赖对人类方案要素抽取的完备性。
6. **检索失败率与召回率的矛盾趋势**：with-search 变体幻觉参考率更高但两变体方案质量结论一致，提示检索开关在本实验配置下既未改善相关工作也未损害最终方案，机制尚不清晰。

### A.4 解读

1. **specter2（PRX 检索适配器）**：把"相关论文"嵌入拉得更紧——类内/类间/贴合度全面上移（Rel 均值 0.865→0.900，类内 0.856→0.887），同时大幅增强了三级匹配中 L3（余弦 ≥ 0.92）的命中：Recall 由 15.7% 升至 24.6%、Precision 由 60.8% 升至 87.6%（Jaccard 0.140→0.232）。即它对"改写标题/不同措辞的同一篇论文"的识别明显优于 base；但其相似带更饱和（多数在 0.88–0.99），**绝对分层面并未缓解"高相似度"观感**。
2. **scibert**：整体相似带**下移且变宽**——类内 0.76–0.80（base 为 0.85–0.87）、Rel 0.78（base 0.865）、类间 0.96–0.97；类内与类间的差距（0.78 vs 0.96）比 base 更大，**"文献是否紧扣 Observation/主题"的区分反而更清晰**；但 L3 命中略降（Recall 14–15%），且 RQ2-2 方案对相似度仍为 0.934–0.960，与 base 几乎无差别。
3. **共同规律**：三个编码器在"同题方案对"（RQ2-2，0.93–0.97）与"相关论文对"上都给出高相似——这说明高绝对值主要来自**语料同质性**（8 篇观测论文同属 ADRS 系统研究合集、对比双方都围绕同一 Observation）与文本本身高度相关，而非编码器缺陷；跨样本的**相对差异**（配对差、H vs L）仍是三个编码器共同的解读基础。
4. **口径提醒**：A.2 中 Recall/Precision/Jaccard 受指南 L3 阈值 0.92 联动（该阈值系按 SPECTER2 语义空间标定），更换编码器后同一阈值的含义随之改变；因此正文 §3.1 的检索指标与结论仍以默认 specter2_base 为准，本附录仅作敏感性佐证。如需进一步拉开区分度（如对向量做白化、或引入交叉编码器校准），可作为后续工作，本实验未采用。
